# Imalafama66 — Portafolio

Portafolio estático listo para Netlify o GitHub Pages.

## Archivos
- `index.html` — estructura y contenido.
- `style.css` — diseño, responsive y animaciones.
- `script.js` — animaciones, menú móvil y barra de progreso.
- `config.js` — datos básicos editables.

## Publicar
Sube todos los archivos a un repositorio de GitHub y activa GitHub Pages, o arrastra la carpeta a Netlify.

## Personalización
Edita `config.js` para nombre, cargo, correo, Discord y GitHub.
